## Thay đổi gì và vì sao

Thêm schema booking_db gồm 11 bảng trên scaffold booking có sẵn. PostgreSQL trực tiếp ngăn hai allocation HELD/SOLD cùng event/seat bằng partial unique index; sau RELEASED ghế được cấp lại. CHECK chặn state/status/type sai (bao gồm COMBO) và sold ngoài [0,total].

Migration tạo bằng `prisma migrate dev --create-only` rồi sửa tay, giữ nguyên khối SQL T-201 và cấu trúc outbox/inbox dùng chung. Migration chạy trong transaction, FK chỉ nội bộ booking_db; cấu hình bắt buộc booking_user/booking_db. Không thêm Lua, API nghiệp vụ hoặc consumer.

Run report: [docs/agent/runs/T-201.md](https://github.com/tvangx/VENTIX/blob/feat/booking-t201-schema/docs/agent/runs/T-201.md).
