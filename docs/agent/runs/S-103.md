## Kế hoạch trước khi code

- OAuth authorization code + PKCE S256; state/nonce một lần, TTL 10 phút, bind với cookie HttpOnly của trình duyệt.
- DB chỉ lưu hash state/cookie; verifier nằm trong cookie HttpOnly, không gửi trong URL. Callback consume state atomically trước khi gọi Google.
- Verify ID token RS256/JWKS, issuer/audience/expiry/nonce/email_verified. Chỉ gọi endpoint Google cố định, timeout.
- Tạo user USER khi chưa có; email trùng tài khoản cũ phải login rồi liên kết rõ ràng. Không tự link bằng email.
- Callback đặt refresh cookie rồi redirect cố định về WEB_ORIGIN/auth/callback; không có token trong URL.
- Google credentials tùy chọn khi dev; nếu thiếu trả 503. Chưa thể xác nhận đăng nhập Google thật khi chưa cấp client ID/secret.
- Test local crypto cho ID token sai chữ ký/audience/nonce; HTTP+PostgreSQL với provider giả cho state/cookie/replay/tạo và link account.
- Tham khảo: https://developers.google.com/identity/openid-connect/openid-connect và RFC 7636. Không thêm thư viện.
