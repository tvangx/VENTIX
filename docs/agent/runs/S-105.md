## Kế hoạch trước khi code

- API tạo/xem hồ sơ Organizer cho owner; upload giấy phép vào bucket private organizer-docs; chỉ owner/Admin được lấy link tải ngắn hạn.
- File PDF/PNG/JPEG, kiểm tra magic bytes + MIME, giới hạn 1 MiB để qua Kong payload 2 MiB hiện có. Không đụng gateway thuộc Tuấn.
- Idempotency tạo hồ sơ/upload. Object key suy ra từ organizer + key UUID; không tin đường dẫn client. Upload thành công mới commit document metadata; DB lỗi có thể để object mồ côi, retry cùng key overwrite đúng nội dung.
- Upload trong transaction có lock hồ sơ và timeout MinIO 5 giây để không đua với duyệt; đường quản trị tải thấp. Chưa dùng presigned upload có thể bị overwrite sau duyệt.
- Admin duyệt/từ chối PENDING với optimistic version; duyệt cần giấy phép; chỉ duyệt thành công mới cấp ORGANIZER scope. Không chuyển scope đang thuộc organizer khác (giới hạn khóa ERD).
- List admin cursor UUID, giới hạn 100. Kiểm tra quyền đang có trong DB, không chỉ role JWT cũ.
- Dùng minio 8.0.6 (Apache-2.0, SDK chính thức) mới. Không thêm event vào Kafka vì hiện không có contract identity/OrganizerApproved; không tự đổi contracts.
- Test HTTP + DB thật, storage adapter giả cho đường lỗi/quyền/idempotency/đua duyệt; test upload SDK riêng. MinIO thật còn phụ thuộc Docker.
