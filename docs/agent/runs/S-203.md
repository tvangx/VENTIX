## Triển khai

- Thêm API gửi duyệt, Admin xem hàng chờ và quyết định, Organizer publish/hủy.
  Quyết định Admin ghi vào event_approvals cùng transaction. Các POST dùng
  version và Idempotency-Key.
- Khi publish, snapshot lấy từ cấu hình Event đã khóa. Hạng vé SEATED cần seat
  map mới nhất khớp các hạng vé, GA-only dùng version 0. Publish seat map,
  chuyển PUBLISHED và enqueue EventApproved v2 cùng transaction.
- Organizer có thể hủy event chưa kết thúc. Hủy event đã công khai enqueue
  EventCancelled v2 cùng transaction. Hủy trước công khai chỉ đổi trạng thái
  Event. T-401 phụ trách hoàn tiền khi có giao dịch.
- Event relay dùng OutboxRelay, xuất metric qua registry hiện có và dừng trước
  khi Prisma ngắt kết nối. Dùng lại thư viện nội bộ và KafkaJS 2.2.4 đã có trong
  repo. Đã thêm cấu hình Kafka vào schema và .env.example.
- [ADR-0013](../../adr/0013-event-publication-lifecycle.md) và Q-S203-01 ghi
  quyết định publish của Sơn. EventUpdated đi cùng luồng sửa sau duyệt đã hoãn.
