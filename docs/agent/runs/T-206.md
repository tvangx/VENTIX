## 3. Đã làm

- Rate riêng holds 60, checkout 20, queue join 30/phút/IP, boundary và chữ hoa/thường tương thích Express. Giữ đường dẫn upstream bằng lookahead, cấu hình router `traditional` rõ trong compose.
- Route không có service chặn `/api/<service>/v1/internal*` bằng request-termination 404; CORS OPTIONS cũng tới termination. Không đổi JWT/admission validation trong service.
- Chuyển fallback rate limit và body limit 2 MiB từ global xuống service public để internal không bị thay bằng 429/413. Identity giữ 120/phút; service còn lại 1200/phút.
- Bản load test nới mọi limiter lên 600000/phút; `make kong-loadtest` nạp qua Admin API loopback, `make kong-reload` khôi phục dev. Không đổi file mount hay secret.
- Smoke test 95 checks với curl thật, hỗ trợ Git Bash (MSYS_NO_PATHCONV + cygpath cho file tạm). README hướng dẫn cấu hình và khôi phục.
