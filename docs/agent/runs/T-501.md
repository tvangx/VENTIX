- Alloy UID 473 tail thư mục log read-only, không Docker socket. Khi log rotate/restart, `local.file_match` phát hiện file mới và checkpoint/reopen tailer. Có thể có một khoảng mất/trùng nhỏ tại ranh giới inode hoặc collector restart; không tuyên bố exactly-once cho file tail.
- Loki retention 7d; Jaeger dùng Badger volume TTL 7d, runtime UID 10001; queue/batch bị giới hạn. Prometheus retention 7d/1GiB. Tổng container cap 2.47GiB/2.75 CPU cho profile 8GiB.
- Outbox chỉ capture `traceparent`/`tracestate` hợp lệ qua OTel propagator trong transaction. Relay tạo producer span rồi inject Kafka headers; Inbox extract riêng mỗi record và tạo consumer span. Null/cũ/sai carrier vẫn xử lý event và tạo trace mới khi phù hợp; không lưu baggage/secret/request context, không dựng ancestry từ payload.
- PostgreSQL monitoring role script chỉ cấp `pg_monitor`, `CONNECT` vào bảy DB và không cấp `USAGE`/`SELECT` schema nghiệp vụ. Kafka/Redis exporters đã chạy local; PG exporter có target down đúng dự kiến do role/DSN chưa được tạo.
- Grafana provisioned datasource Prometheus/Loki/Jaeger và dashboard RED, System, Business, Logs & Traces. System/Business biểu thị rõ No data/target down thay vì báo khỏe giả.
- Runbook mô tả migration trước image mới, rebuild các image ứng dụng, role monitoring, start/check/smoke/stop/rollback bảo toàn `.env.prod`, `.env.demo`, Tunnel token và volumes.
